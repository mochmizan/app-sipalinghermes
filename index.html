Apa itu Si Paling Hermes?

Bukan chatbot bersama. Ini agent yang kamu atur sendiri.

Satu runtime Hermes terpisah per user/agent pada MVP. Konfigurasi, memori, chat, mapping, dan action log tidak dicampur.

01

Runtime terpisah

Data persisten, konfigurasi, volume, dan batas resource agent-mu punya ruang sendiri.

02

Model pilihanmu

BYOK memungkinkan kamu membawa credential provider LLM yang tersedia dan lulus compatibility test.

03

Social media terhubung

Sipalinghermes menjadi gateway. Capability mengikuti plan dan hasil endpoint test, bukan sekadar nama fitur.

04

Tetap di bawah kendalimu

Atur policy, nonaktifkan capability, putus koneksi, atau tekan OFF tanpa menghapus konfigurasi.

Cara kerja

Dari setup sampai action, semuanya terlihat.

Mulai dari satu deployment yang dapat diukur. Perluas setelah capability dan hasilnya terbukti.

01

Atur agent

Pilih template, beri nama, tulis tujuan, persona, brand voice, dan execution policy.

02

Hubungkan model

Masukkan credential LLM melalui HTTPS. Secret tidak ditampilkan ulang setelah tersimpan.

03

Hubungkan akun

Pilih platform, selesaikan OAuth atau asset selection, lalu ownership divalidasi.

04

Deploy runtime

Platform menyiapkan workspace persisten, batas resource, dan runtime terpisah.

05

Perintah Hermes

Gunakan web chat untuk membaca queue, menyiapkan draft, atau menjalankan action.

06

Pantau & kendalikan

Periksa status, hasil action, error, capability, dan ubah ON/OFF saat dibutuhkan.
