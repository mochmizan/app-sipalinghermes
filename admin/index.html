System Settings

Fakta operasional runtime Hermes. Hanya nilai yang benar-benar berlaku di agent-runtime.mjs.

Server-managed
01

Runtime tick

Tick 5 detik. Job yang macet di status running lebih dari 5 menit dikembalikan ke queue oleh reaper.

02

Dead-letter

Job gagal dicoba ulang maksimal 3 kali dengan error terpotong; setelah itu status failed dan hanya bisa dikembalikan lewat requeue admin.

03

Report mingguan

Satu job scheduled_report per ISO week strftime('%G-W%V') dengan INSERT OR IGNORE, untuk agent aktif yang capability report-nya nyala. Manual report kapan saja.

04

Rate limit chat

20 pesan per menit per user, maksimal 2 percakapan berjalan sekaligus. 429 membawa Retry-After 60 detik.

05

Timeout LLM

Satu panggilan chat dibatasi 90 detik (max_tokens 500, konteks 12 pesan terakhir), error hanya dari kode tertutup.

06

Retensi

Tidak ada penghapusan otomatis untuk pesan, job, dan audit (retensi unlimited). Baris hanya hilang lewat cascade saat agent atau user dihapus.
